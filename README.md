# METRO DASH

Subway Surfers 느낌의 3레인 엔들리스 러너 웹 게임.

**3D.js는 없습니다.** 웹 3D 표준은 [Three.js](https://threejs.org) 입니다. 이 프로젝트는 Three.js + Vite로 만들었습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 을 엽니다.

## 테스트

```bash
npm test          # 1회 실행
npm run test:watch
```

시뮬레이션 순수 로직(충돌·페이스·점수·타임스텝)은 렌더러 없이 단위 테스트로 검증합니다. 백엔드는 `convex-test`로 인메모리 Convex를 띄워 함수가 **실제로 DB에 뭘 쓰는지**까지 확인합니다 — 순수 함수 테스트로는 보이지 않는 부분이라, 프로덕션까지 갔던 버그 두 개가 모두 여기에 걸립니다.

## 장애물

- **마주 오는 버스** — 헤드라이트가 보이면 레인을 바꾸세요
- **바리케이드** — 점프
- **노란 게이트** — **슬라이드 전용.** 구조물이 점프 최고점(슈퍼 스니커즈 포함)보다 높아 점프로는 절대 넘을 수 없습니다
- **상자** — 점프 또는 회피

## 파워업

| 파워업 | 효과 |
| --- | --- |
| 🧲 자석 | 주변 코인을 끌어당깁니다 |
| 🚀 제트팩 | 고도 6.2m로 날아 모든 장애물을 넘습니다 |
| ✦ 점수 2배 | 획득 점수가 두 배 |
| 👟 슈퍼 스니커즈 | 점프가 높아집니다 (게이트는 여전히 못 넘습니다) |
| 🛹 호버보드 | 상점에서 구매 · 점프를 두 번 빠르게 입력하면 꺼내지고, 충돌 1회를 막아줍니다 |

지속 시간은 상점에서 Lv.5까지 강화할 수 있습니다.

## 진행 요소

- **코인** — 판이 끝나면 은행에 적립되고, 상점에서 파워업 강화 · 호버보드 · 캐릭터 해금에 씁니다
- **미션** — 20종 풀에서 항상 3개가 굴러가며, 달성하면 코인과 XP를 주고 즉시 새 미션으로 교체됩니다. 각 미션은 난이도 7단계를 가지고 랭크가 오를 때마다 한 단계씩 올라갑니다
- **랭크** — XP가 쌓이면 랭크가 오르고, 그때마다 미션 목표치가 한 단계 높아집니다
- **콤보** — 코인 · 아슬아슬 통과 · 지붕 탑승이 콤보를 이어가고, 콤보 등급이 점수 배율을 올립니다
- **아슬아슬 보너스** — 장애물을 아슬아슬하게 스치거나 낮게 넘으면 보너스가 붙습니다

## 설정

타이틀 → **설정**에서 효과음 · 배경음악 · 진동 · 화질을 조절합니다. 화질은 기본이 **자동**이며, 프레임이 떨어지면 픽셀 비율 · 그림자 · 파티클 · 시야거리를 한 단계씩 낮춥니다. 한 번 버거웠던 단계로는 다시 올라가지 않습니다.

## 온라인 (선택)

`VITE_CONVEX_URL`이 없으면 게임은 **완전한 오프라인 모드**로 동작합니다. 로그인 화면도, 리더보드도 뜨지 않고 저장은 브라우저에만 남습니다. 온라인 기능은 전부 그 위에 얹히는 층입니다.

- **계정** — 닉네임 + 숫자 4자리. 이름도 이메일도 받지 않으므로 서버에 남는 개인정보가 없습니다.
- **저장** — 코인 · 강화 · 미션 · 랭크까지 프로필 전체가 올라가고, 다른 기기에서 로그인하면 그대로 이어집니다.
- **리더보드** — 서버가 인정한 기록만 올라갑니다. 클라이언트 저장은 최고점을 건드리지 못합니다.
- **학교** — 선택 사항입니다. 정하면 학교 랭킹에 참여합니다.

### 학교 랭킹

리더보드는 한 화면에 **개인 10위 · 학교 10위**를 좌우로 놓습니다. 학교 점수는 그 학교 구성원 **전원의 최고 점수를 더한 값**입니다.

학교는 가입 직후 한 번 물어보고, 나중에 타이틀 화면에서 정할 수도 있습니다. **한 번 정하면 학생은 바꿀 수 없습니다** — 바꿀 수 있으면 이기고 있는 학교로 점수를 들고 옮겨 다닐 수 있어서 랭킹이 의미를 잃습니다. 잘못 골랐다면 관리자 화면에서 고칩니다.

같은 학교가 여러 줄로 갈라지는 것을 막는 게 핵심입니다.

- **지역과 학교급은 목록에서 고릅니다.** 직접 쓰는 건 학교 이름뿐입니다.
- **접미사는 알아서 떨어집니다.** 「동」 · 「동중」 · 「동중학교」 모두 `대구 동중학교` 한 줄로 갑니다. 「동중중학교」 같은 건 생기지 않습니다.
- **여중 · 남고도 합쳐집니다.** 「성화여중」과 「성화여자중학교」는 같은 학교입니다.
- **학교급이 어긋나면 거절합니다.** 중학교를 고르고 「계성초등학교」를 쓰면 저장하지 않고 되묻습니다. 조용히 고쳐서 없는 학교를 만들어내는 쪽이 더 나쁩니다.
- **입력하는 동안 결과를 보여줍니다.** 「동중」이라고 치면 그 자리에서 `→ 대구 동중학교`가 뜨고, 확정 전에 한 번 더 확인합니다.
- 그래도 오타로 갈라지면 관리자 화면에서 **두 학교를 합칠 수 있습니다.**

#### 학교 이름 자동완성 (선택)

`src/data/schools.json` 이 비어 있으면 학교 이름을 직접 입력합니다. 전국 학교 목록을 채워 넣으면 자동완성이 붙습니다.

```bash
NEIS_KEY=발급받은키 node scripts/fetch-schools.mjs
```

키는 [나이스 교육정보 개방 포털](https://open.neis.go.kr)에서 무료로 즉시 발급됩니다. 받아온 JSON은 커밋되며, 게임은 실행 중에 이 API를 부르지 않고 배포에도 키가 들어가지 않습니다. 목록은 학교 폼을 열 때만 별도 청크로 내려받으므로 게임 번들에는 영향이 없습니다.

### 장난 막기

한 반에서 굴리는 것을 전제로 만든 장치들입니다.

- **닉네임 필터** — 완성형 한글과 영숫자만 허용하고, 자모 분해 · 유사 문자 치환 · 보이지 않는 문자를 접은 뒤에 금칙어를 검사합니다.
- **신고** — 필터는 글자를 끼워 넣은 우회를 잡지 못합니다. 리더보드의 🚩 버튼으로 신고하면 관리자 화면에 모입니다. 한 사람이 같은 대상을 여러 번 신고해도 1건입니다.
- **기기당 계정 3개** — 한 브라우저에서 계정을 찍어내지 못하게 막습니다. 브라우저 데이터를 지우면 우회되는, 의도적으로 가벼운 방벽입니다.
- **로그인 잠금** — 5회까지는 그냥 틀리고, 그 다음부터 30초 · 60초 · 120초로 늘어납니다. 4자리 비밀번호를 실제로 지키는 건 이 잠금입니다.
- **기록 검증** — 제출된 기록은 속도 곡선이 허용하는 최대 거리 · 코인 · 점수와 대조해서, 불가능한 숫자는 조용히 떨어뜨립니다.

### 관리자 화면

`/admin.html` 로 들어가서 Convex 대시보드에 설정한 `ADMIN_KEY`를 입력합니다. 키는 그 탭에만 남고 매 요청마다 서버에서 다시 검사하므로, 이 페이지 자체는 아무 권한도 갖고 있지 않습니다.

신고 목록 확인 · 강제 개명 · 비밀번호 초기화 · 잠금 해제 · 계정 삭제, 그리고 학교 지정 · 변경 · 삭제와 갈라진 학교 병합을 할 수 있습니다. 개명하면 리더보드에 박혀 있던 이름까지 함께 따라가고, 그 신고는 처리 완료로 정리됩니다.

```bash
npx convex env set ADMIN_KEY '아무도 모를 긴 문자열' --prod
```

## 배포

`main`에 푸시하면 Vercel이 `npm run build:vercel`을 돌립니다.

```
convex deploy --cmd 'vite build'
```

한 명령 안에서 **백엔드 함수를 프로덕션에 올린 뒤** 그 배포의 URL을 `VITE_CONVEX_URL`로 주입해 프런트엔드를 빌드합니다. 백엔드만 먼저 올리거나 프런트만 먼저 올려서 어긋나는 구간이 없습니다.

Vercel에 필요한 환경변수는 `CONVEX_DEPLOY_KEY` 하나입니다 (Convex 대시보드 → Production → Deploy key). `VITE_CONVEX_URL`은 빌드가 직접 채우므로 등록하지 않습니다. 브랜치 푸시는 프리뷰 배포가 되지만 같은 프로덕션 백엔드를 보므로, 스키마를 바꾸는 작업은 브랜치에서 확인하지 말고 `npx convex dev`로 개발 배포에서 확인합니다.

### 설계 노트

- 시뮬레이션은 **고정 타임스텝**(1/120초)으로 돌고 렌더링만 프레임마다 수행합니다.
- 충돌은 프레임 끝 위치가 아니라 **한 스텝 동안 훑고 지나간 구간**을 검사하므로, 고속에서 얇은 장애물을 통과해버리지 않습니다.
- 장애물 배치는 `patterns.js`의 **데이터 테이블**에서 나옵니다. 스포너는 메시를 만들기 전에 각 패턴이 차지하는 구간과 요구 동작을 검사해서, 겹치거나 회피 불가능한 배치를 막습니다.
- **게이트는 어떤 파워업으로도 넘을 수 없습니다.** 구조물 높이가 슈퍼 스니커즈 최고점보다 위에 있고, 이 불변식은 테스트로 고정돼 있습니다.
- 아슬아슬 판정은 거리만 보지 않습니다. 레인 전환이 0.19초면 끝나기 때문에, **막판에 피했는지**를 함께 봅니다.
- `run.js`가 점수와 정산을 전담합니다. 한 판이 사망 시점과 종료 시점에 두 번 정산되므로 모든 적립은 **델타**로 처리되고, 미션 재발급은 판이 완전히 끝난 뒤에만 일어납니다.
- 저장 데이터는 손상되거나 손으로 수정돼도 항상 유효한 프로필로 정규화됩니다 — 없는 캐릭터, 범위 밖 강화 레벨, 음수 재화는 모두 걸러집니다.
- 리더보드가 순위를 매기는 `best`는 **서버만 씁니다.** 프로필 저장은 이 값을 건드릴 수 없고, 저장 blob 안에 들어 있는 사본까지 서버 값으로 덮어씁니다.
- 학교 합계는 매번 계산하지 않고 **증분으로 갱신합니다.** 플레이어 문서에 세이브 파일이 통째로 들어 있어서, 전원을 읽어 더하면 쿼리 읽기 한도에 걸립니다. 대신 어긋났을 때 되돌릴 `admin:recomputeSchools` 가 있습니다.
- 로그인 실패는 예외를 던지지 않고 **결과값으로 돌려줍니다.** Convex는 예외가 난 뮤테이션을 통째로 롤백하므로, 던지면 실패 횟수를 올린 그 쓰기까지 같이 사라져 잠금이 영원히 걸리지 않습니다.
