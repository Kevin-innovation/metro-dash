# METRO DASH

Subway Surfers 느낌의 3레인 엔들리스 러너 웹 게임.

**3D.js는 없습니다.** 웹 3D 표준은 [Three.js](https://threejs.org) 입니다. 이 프로젝트는 Three.js + Vite로 만들었습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 을 엽니다.

## 테스트

```bash
npm test          # 1회 실행
npm run test:watch
```

시뮬레이션 순수 로직(충돌·페이스·점수·타임스텝)은 렌더러 없이 단위 테스트로 검증합니다.

## 조작

| 동작 | 키보드 | 모바일 |
| --- | --- | --- |
| 레인 변경 | ← → / A D | 좌우 스와이프 |
| 점프 | ↑ / W / Space | 위로 스와이프 |
| 슬라이드 | ↓ / S | 아래로 스와이프 |
| 점프 캔슬 | 점프 중 ↓ | 점프 후 아래로 스와이프 |
| 버스/열차 탑승 | 점프해서 지붕에 착지 | 같은 조작 |
| 일시정지 | P / Esc | 우측 상단 버튼 |

## 장애물

- **열차** — 레인을 바꾸거나 점프해서 지붕에 올라타세요
- **마주 오는 버스** — 헤드라이트가 보이면 레인을 바꾸세요
- **바리케이드** — 점프
- **노란 게이트** — **슬라이드 전용.** 구조물이 점프 최고점(슈퍼 스니커즈 포함)보다 높아 점프로는 절대 넘을 수 없습니다
- **상자** — 점프 또는 회피

## 파워업

| 파워업 | 효과 |
| --- | --- |
| 🧲 자석 | 주변 코인을 끌어당깁니다 |
| 🚀 제트팩 | 고도 6.2m로 날아 모든 장애물을 넘습니다 |
| ✦ 점수 2배 | 획득 점수가 두 배 |
| 👟 슈퍼 스니커즈 | 점프가 높아집니다 (게이트는 여전히 못 넘습니다) |
| 🛹 호버보드 | 상점에서 구매 · <kbd>B</kbd>로 꺼내면 충돌 1회를 막아줍니다 |

지속 시간은 상점에서 Lv.5까지 강화할 수 있습니다.

## 진행 요소

- **코인** — 판이 끝나면 은행에 적립되고, 상점에서 파워업 강화 · 호버보드 · 캐릭터 해금에 씁니다
- **미션** — 항상 3개가 굴러가며, 달성하면 코인과 XP를 주고 즉시 새 미션으로 교체됩니다
- **랭크** — XP가 쌓이면 랭크가 오르고 미션 난이도가 올라갑니다
- **부활** — 죽은 자리에서 코인을 내고 이어 달릴 수 있습니다 (판당 최대 3회, 가격은 매번 2배)
- **콤보** — 코인 · 아슬아슬 통과 · 지붕 탑승이 콤보를 이어가고, 콤보 등급이 점수 배율을 올립니다
- **아슬아슬 보너스** — 장애물을 아슬아슬하게 스치거나 낮게 넘으면 보너스가 붙습니다

## 설정

타이틀 → **설정**에서 효과음 · 배경음악 · 진동 · 화질을 조절합니다. 화질은 기본이 **자동**이며, 프레임이 떨어지면 픽셀 비율 · 그림자 · 파티클 · 시야거리를 한 단계씩 낮춥니다. 한 번 버거웠던 단계로는 다시 올라가지 않습니다.

├── entities.js     장애물/픽업 메시와 오브젝트 풀

├── textures.js     절차적 캔버스 텍스처
├── particles.js    풀링된 파티클 필드 (단일 드로우콜)
├── input.js        키보드 · 스와이프 입력

├── bgm.js          절차적 배경음악 (페이즈별 레이어)

├── interactions.js 픽업 · 아슬아슬 · 충돌 판정 해석
├── screens.js      모든 DOM 접근 (오버레이 · 상점 · 설정 · 결과창)
├── ui.js           HUD · 상점 · 미션 · 랭크 렌더링
│
│   -- 아래는 렌더러 없이 단위 테스트되는 순수 모듈 --
├── run.js          런 점수 · 콤보 · 미션 정산
├── collision.js    스윕(연속) 충돌 · 아슬아슬 판정
├── patterns.js     장애물 패턴 테이블과 공정성 메타데이터
├── specs.js        엔티티 물리 명세
├── pace.js         속도/페이즈 곡선
├── scoring.js      점수 · 콤보 배율 규칙
├── powerups.js     파워업 타이머와 효과
├── missions.js     미션 정의 · 굴리기 · 진행도
├── progression.js  랭크와 XP

### 설계 노트

- 시뮬레이션은 **고정 타임스텝**(1/120초)으로 돌고 렌더링만 프레임마다 수행합니다.
- 충돌은 프레임 끝 위치가 아니라 **한 스텝 동안 훑고 지나간 구간**을 검사하므로, 고속에서 얇은 장애물을 통과해버리지 않습니다.
- 장애물 배치는 `patterns.js`의 **데이터 테이블**에서 나옵니다. 스포너는 메시를 만들기 전에 각 패턴이 차지하는 구간과 요구 동작을 검사해서, 겹치거나 회피 불가능한 배치를 막습니다.
- **게이트는 어떤 파워업으로도 넘을 수 없습니다.** 구조물 높이가 슈퍼 스니커즈 최고점보다 위에 있고, 이 불변식은 테스트로 고정돼 있습니다.
- 아슬아슬 판정은 거리만 보지 않습니다. 레인 전환이 0.19초면 끝나기 때문에, **막판에 피했는지**를 함께 봅니다.
- `run.js`가 점수와 정산을 전담합니다. 부활 때문에 한 판이 여러 번 정산될 수 있어서 모든 적립은 **델타**로 처리되고, 미션 재발급은 판이 완전히 끝난 뒤에만 일어납니다.
- 저장 데이터는 손상되거나 손으로 수정돼도 항상 유효한 프로필로 정규화됩니다 — 없는 캐릭터, 범위 밖 강화 레벨, 음수 재화는 모두 걸러집니다.
